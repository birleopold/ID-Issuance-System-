# Credential Studio — product description

Credential Studio is a desktop identity card issuance application that gives organizations a consistent way to enroll cardholders, capture photographs and signatures, design branded credentials, approve records and print cards from a single Windows workstation. Its guided workspace connects each card to a saved record and a visible issuance history, helping staff correct mistakes before printing and account for reprints afterward.

Designed for reception teams, HR departments, school administration and membership desks, the application works locally without depending on internet connectivity. Operators can begin with a prepared front-and-back card layout or import an organization’s artwork, then position identity fields precisely. The same renderer produces the on-screen preview, PDF and print image.

## Intended customer experience

- **Simple installation:** one Windows setup package; no Python setup or command-line work for the operator.
- **Clear next action:** enrollment follows details, portrait, signature, review and printing.
- **Immediate feedback:** preview updates during editing; incomplete enrollment and text overflow are shown before approval or output.
- **Predictable ownership:** operators enroll and print approved cards; administrators manage templates, approvals, revocation and reprints.
- **Recoverable interruptions:** pending jobs remain visible after restart and must be resolved before retrying.
- **Local control:** records and images stay on the workstation; administrators can make complete backups and recover into a separate folder.

## Included customer deliverables

1. Windows setup package generated by a successful Windows build.
2. Two adaptable CR80 front/back templates.
3. Installed application and configured organization branding.
4. Operator and administrator accounts created during handover.
5. Printer calibration and test credentials on the selected hardware.
6. Backup location, restore drill, operator walkthrough and written acceptance.

Items 3–6 are deployment activities, not outcomes established by this repository alone.

## Product positioning

Suggested short description: **“A professional Windows workspace for creating, approving and printing branded identity cards—with photo capture, signatures, reusable templates and traceable issuance.”**

Suggested pitch: **“Give your team one clear process for every identity card. Credential Studio combines enrollment, portraits, signatures, design and printing in a focused desktop application, with approval controls and a record of what was issued.”**

The present implementation is suitable for a supervised pilot. Production readiness must be demonstrated against the chosen devices, target Windows image, workload, privacy requirements and customer acceptance criteria. Avoid marketing untested hardware compatibility, tamper-proof logs, encrypted databases or national identity verification.
